# RunSentry Feedback Questions

Use these questions for early demand validation. Ask for sanitized summaries only; users
should not share secrets, private command arguments, or private paths.

1. Did install from source work?
2. What OS and Python version did you use?
3. What command or kind of workload did you wrap?
4. Did RunSentry preserve the command behavior and visible stdout/stderr?
5. Did the health state match your own judgment?
6. Was `summary.json` useful after the run?
7. Were the telemetry/privacy warnings clear?
8. Did watched-path facts help you understand whether output was still changing?
9. What missing feature or missing fact blocked real use?
10. Would PyPI installation materially matter?
11. Would notifications, a remote view, or multi-machine observation matter?
12. Would you use this weekly, and would you pay for a hosted/remote/team version later?
